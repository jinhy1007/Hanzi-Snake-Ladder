怎么测

    
    
      
  1. 先点「🎙️ 先测一下麦克风」，说几句话，看绿色条有没有跳。没跳的话：打开 Mac 的「系统设置 → 隐私与安全性 → 麦克风」，确认 Chrome / Safari 打开了；再看「系统设置 → 声音 → 输入」选的是哪个麦克风，说话时输入电平有没有动。
    2. 
      
  2. 第一次点话筒，浏览器会问能不能用麦克风，点「允许」。
    3. 
      
  3. 让小朋友看着字，点话筒后读出来。读完会显示「读对了」或「好像不对」。
    4. 
      
  4. 家长点「实际读对了 / 实际读错了」，告诉测试页真实情况，然后自动换下一个字。
    5. 
      
  5. 也可以故意读错几个，看它能不能发现。最好是小朋友真会犯的错：读错声调（比如把「妈」读成 mǎ）、
        相近的音（zh / z、an / ang、n / l），或者把长得像的字读错（大 / 太、人 / 入）。
    6. 
      
  6. 测 20 个左右后，点「复制结果发给 Claude」，粘贴给我。手机和电脑最好都测一下。
